O projeto Painel de Preços de Combustíveis consiste em um sistema web interativo
desenvolvido por Robson Douro Gonçalves, aluno do curso de Bacharel em Sistemas de Informação, da Universidade Vila Velha.
O objetivo principal da aplicação é centralizar e divulgar o histórico cronológico de coletas comerciais
realizadas no município de Marechal Floriano/ES.
A ferramenta unifica as etapas de modelagem, arquitetura e normalização de dados (AOP1 e AOP2)
em uma interface front-end limpa, permitindo que o cidadão consulte de forma dinâmica os valores
de mercado por meio de filtros individuais de postos, bairros e combustíveis.
